# Памятка: диагностика физики линка с SFP-модулями

> Цифры даны по IEEE 802.3 (средняя мощность, avg). ZX и 10G-ZR не являются стандартами IEEE, их параметры задают вендоры и MSA.
> Точные значения для конкретного модуля сверяйте с его datasheet и с порогами в DOM (SFF-8472).

## 1. Типы SFP и что они значат

**Мультимод (MMF), 850 нм**

| Тип | Волокно и дистанция | Коннектор |
|---|---|---|
| 1000BASE-SX | OM1 275 м · OM2 550 м · OM3/OM4 ~550 м | LC duplex |
| 10GBASE-SR | OM1 33 м · OM2 82 м · OM3 300 м · OM4 400 м | LC duplex |
| 25GBASE-SR | OM3 70 м · OM4/OM5 100 м | LC duplex |
| 40GBASE-SR4 | OM3 100 м · OM4/OM5 150 м | MPO-12 |
| 100GBASE-SR4 | OM3 70 м · OM4/OM5 100 м | MPO-12 |

**Одномод (SMF, OS1/OS2)**

| Тип | λ, нм | Дистанция | Коннектор |
|---|---|---|---|
| 1000BASE-LX | 1310 | 5 км (LX/LH у вендоров обычно 10 км); MMF до 550 м с mode-conditioning патчкордом | LC duplex |
| 1000BASE-ZX * | 1550 | 70–80 км | LC duplex |
| 10GBASE-LR | 1310 | 10 км | LC duplex |
| 10GBASE-ER | 1550 | 40 км (30 км engineered) | LC duplex |
| 10GBASE-ZR * | 1550 | 80 км | LC duplex |
| 100GBASE-LR4 | 4 λ ~1295–1310 (LAN-WDM) | 10 км | LC duplex |

\* не стандарт IEEE, параметры вендора.

## 2. DOM-параметры: что читать

| Параметр | Ед. | Что означает |
|---|---|---|
| TX power | dBm | Мощность, которую излучает лазер нашего модуля |
| RX power | dBm | Мощность, пришедшая от дальнего конца, то есть его TX минус затухание линии |
| Bias current | mA | Ток лазера. Рост тока при той же TX-мощности говорит о деградации лазера |
| Temperature | °C | Температура модуля, обычно 0..70 (commercial) или −40..85 (industrial) |
| Voltage | V | Питание модуля, норма 3.3 В ±5% (3.13–3.47 В) |
| TX fault | флаг | Модуль сообщил об отказе передатчика |
| RX loss (LOS) | флаг | Нет оптического сигнала на входе: RX ниже порога детекции |

Пороги low/high warning и alarm зашиты в EEPROM модуля и выводятся в детальном выводе transceiver/DOM.

## 3. Нормальные показания RX/TX по типам модулей

Для многолинейных модулей (SR4, LR4) значения указаны на одну линию.

| Тип | TX, dBm | RX sens, dBm | RX max, dBm |
|---|---|---|---|
| 1000BASE-SX | −9.5 … 0 (у вендоров обычно до −3) | −17 | 0 |
| 1000BASE-LX | −11 … −3 (у вендоров LX/LH −9.5 … −3) | −19 (у вендоров LH до −20) | −3 |
| 1000BASE-ZX * | 0 … +5 | −23 (у части вендоров −24) | −3 |
| 10GBASE-SR | −7.3 … −1.0 | −9.9 | −1.0 |
| 10GBASE-LR | −8.2 … +0.5 | −14.4 | +0.5 |
| 10GBASE-ER | −4.7 … +4.0 | −15.8 | −1.0 |
| 10GBASE-ZR * | 0 … +4 | −24 | −7 |
| 25GBASE-SR | −8.4 … +2.4 | −10.3 | +2.4 |
| 40GBASE-SR4 | −7.6 … +2.4 | −9.5 | +2.4 |
| 100GBASE-SR4 | −8.4 … +2.4 | −10.3 | +2.4 |
| 100GBASE-LR4 | −4.3 … +4.5 | −10.6 | +4.5 |

\* вендор или MSA, не IEEE.

**Пороги warning и alarm.**
- Задаются вендором и хранятся в DOM.
- Типичная картина: warning близко к границе спецификации, alarm примерно на 1–3 dB дальше.
- Пример для 10G-LR: RX low warn около −14.4…−16, RX low alarm около −18…−20 dBm.
- Ориентируйтесь на пороги, которые показывает сам модуль.

**Источники цифр.**
- IEEE 802.3, разделы 38, 52, 86, 88 и 95.
- Datasheet Cisco на модули SFP, SFP+, SFP28, QSFP+ и QSFP100.
- Datasheet FS для 25G-SR.

Для SR4 и 100G официальная чувствительность задана через OMA. Значение avg RX min носит справочный характер и не является главным критерием.

**Перегруз приёмника.** Если RX выше RX max (ER и ZR на коротком линке), приёмник перегружен. Нужен аттенюатор на 5–10 dB.

## 4. Бюджет затухания (link budget)

```text
Бюджет      = TX (dBm) - RX sensitivity (dBm)
Потери      = L(км) * a(дБ/км) + N_конн * потери_конн + N_сварок * потери_сварки
Запас       = Бюджет - Потери           -> должен быть >= 3 dB
Ожидаемый RX = TX - Потери              -> должен быть выше sensitivity минимум на 3 dB
```

| Элемент | Типичные потери |
|---|---|
| SMF, 1310 нм | 0.3–0.4 dB/км |
| SMF, 1550 нм | 0.2–0.25 dB/км |
| MMF OM3, 850 нм | ~3.5 dB/км (≈0.35 dB на 100 м) |
| LC-пара (коннектор) | 0.3–0.75 dB |
| Сварка | 0.05–0.1 dB |
| Запас | ≥ 3 dB |

**Пример: 10GBASE-LR, 10 км одномода, 1310 нм.**

Потери линии:

| Элемент | Расчёт | dB |
|---|---|---|
| Волокно | 10 км × 0.35 | 3.5 |
| Коннекторы (2 кросса) | 2 × 0.5 | 1.0 |
| Сварки | 4 × 0.1 | 0.4 |
| **Итого потерь** | | **4.9** |

Два варианта по TX:

| Сценарий | Бюджет | Запас | Ожидаемый RX |
|---|---|---|---|
| Лучший TX = +0.5 dBm | 0.5 − (−14.4) = **14.9 dB** | 14.9 − 4.9 = **10.0 dB** ✓ | 0.5 − 4.9 = **−4.4 dBm** |
| Худший TX = −8.2 dBm (минимум по стандарту) | −8.2 − (−14.4) = **6.2 dB** | 6.2 − 4.9 = **1.3 dB** ✗ (< 3 dB) | −8.2 − 4.9 = **−13.1 dBm** |

**Вывод.** Считайте бюджет по минимальному TX из спецификации, а не по максимальному. Бюджет 14.9 dB — это лучший случай. Гарантированный бюджет по стандарту 6.2 dB (IEEE допускает потери канала LR до 6.2 dB). Линия на 10 км с двумя кроссами укладывается только впритык. Улучшить можно так:
- уменьшить число кроссов;
- проверить реальный TX по DOM;
- взять модуль с бо́льшим бюджетом (например, ER, при необходимости с аттенюатором).

## 5. Типичные симптомы по показаниям

| Симптом | Вероятная причина |
|---|---|
| CRC/FCS растут при нормальном RX | Проблема на приёме: дальний конец или кабель |
| RX в норме, но линк флапает | Автонег или дуплекс |
| RX ниже sensitivity | Затухание или грязный коннектор |
| TX fault | Сам модуль |
| TX и RX падают симметрично на обеих сторонах | Кабель или соединение посередине |
| Асимметрия: одна сторона видит плохой RX, другая нормальный TX | Направленная проблема в одном волокне пары |

## 6. Практика диагностики с нуля

1. `show interface`: CRC, symbol errors, runts.
2. DOM: снять TX и RX с **обеих** сторон.
3. Сравнить RX с sensitivity модуля (раздел 3).
4. Посчитать link budget с учётом длины и числа коннекторов (раздел 4).
5. Почистить LC-коннекторы (one-click cleaner) и переподключить.
6. Вынуть и вставить SFP, сравнить модели и ревизии на обеих сторонах.
7. Если линк идёт через кросс или медиаконвертер, проверить его.
8. Заменить патчкорд на заведомо хороший.
9. Loopback-тест модуля. Для SMF ставьте аттенюатор, чтобы не перегрузить приёмник.
10. При смешанных скоростях 100/1000 зафиксировать speed и duplex вручную.

## 7. Быстрая шпаргалка-минимум

```text
1. RX выше sensitivity минимум на 3 dB (и ниже RX max)
2. CRC/FCS не растут
3. Нет TX fault и RX loss
4. TX/RX симметричны с двух сторон (RX_A = TX_B - потери, и наоборот)
5. Температура модуля в допуске (0..70 °C commercial)
```
