# Урок 02. Маски подсети

_Блок 1. Основы_

```text
Длительность: 60 секунд. Формат: вертикальное видео 9:16 (YouTube Shorts / TikTok).
Стиль: тёмный фон (почти чёрный), моноширинный шрифт, зелёный текст как в терминале, эффект набора текста. Без логотипов, без музыки на фоне голоса, без воды — только суть.

Тема: Урок 02. Маски подсети.

Сюжет по сценам:
0–5 с — хук: Вопрос крупно: /24 или 255.255.255.0 — это одно и то же?
5–20 с — Маска в битах: 11111111.11111111.11111111.00000000 = /24 = 255.255.255.0
20–40 с — Таблица: /24 → 256 адресов, 254 хоста · /26 → 64 адреса, 62 хоста · /30 → 4 адреса, 2 хоста. Формула: хосты = 2^(32−префикс) − 2
40–55 с — Пример: 192.168.10.70/26 → сеть 192.168.10.64, broadcast 192.168.10.127, хосты .65–.126
55–60 с — финальная строка крупно по центру: «Хосты = 2^(32 − префикс) − 2.»

Закадровый голос (спокойный, уверенный, по-русски):
Маска — это как линия на карте, которая отделяет название района от номера дома. Единицы в маске — это район, нули — дома в нём. Запись слэш двадцать четыре значит двадцать четыре единицы, то есть двести пятьдесят пять, двести пятьдесят пять, двести пятьдесят пять, ноль. Чем больше префикс, тем меньше домов в районе. Слэш двадцать шесть — шестьдесят четыре адреса, из них шестьдесят два для устройств: первый адрес — имя самой сети, последний — общий громкоговоритель, broadcast. Пример: адрес семидесятый в сети слэш двадцать шесть живёт в блоке от шестьдесят четвёртого до сто двадцать седьмого. Считай по формуле: два в степени нулей минус два — и не ошибёшься.

Финальная строка-вывод: Хосты = 2^(32 − префикс) − 2.
```
