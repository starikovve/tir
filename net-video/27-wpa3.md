# Урок 27. WPA3

_Блок 6. Беспроводные сети_

```text
Длительность: 60 секунд. Формат: вертикальное видео 9:16 (YouTube Shorts / TikTok).
Стиль: тёмный фон (почти чёрный), моноширинный шрифт, зелёный текст как в терминале, эффект набора текста. Без логотипов, без музыки на фоне голоса, без воды — только суть.

Тема: Урок 27. WPA3.

Сюжет по сценам:
0–5 с — хук: Пароль от Wi-Fi подслушали — а расшифровать не смогли.
5–20 с — Эволюция: WEP (взломан) → WPA → WPA2 (AES-CCMP, PSK уязвим к офлайн-перебору) → WPA3
20–40 с — WPA3-Personal: SAE вместо PSK — защита от офлайн-подбора, forward secrecy · WPA3-Enterprise: 802.1X + RADIUS, опция 192-bit · обязательный PMF (802.11w)
40–55 с — Переходный режим WPA2/WPA3 для старых клиентов · Enhanced Open (OWE) — шифрование в открытых сетях без пароля
55–60 с — финальная строка крупно по центру: «WPA3 = SAE + PMF; в офисе — 802.1X.»

Закадровый голос (спокойный, уверенный, по-русски):
WPA3 — это как замок, который нельзя подобрать, даже если унести дверь домой и ковырять её неделю. В WPA2 с общим паролем злоумышленник мог записать рукопожатие и спокойно перебирать пароли у себя дома. В WPA3 вместо этого используется SAE — обмен, при котором перехват ничего не даёт для перебора. Плюс прямая секретность: старый трафик не расшифровать, даже узнав пароль. Защита управляющих кадров стала обязательной, поэтому клиента сложнее выбить из сети. В корпоративной сети — 802.1X с RADIUS. Для старых устройств есть переходный режим, но он слабее чистого WPA3.

Финальная строка-вывод: WPA3 = SAE + PMF; в офисе — 802.1X.
```
