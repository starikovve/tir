```text
Закадровый голос (спокойный, уверенный, по-русски):
IPv6 — это как перейти с городских телефонных номеров на номера с кодом страны: адресов столько, что хватит каждой песчинке. Адрес длиной сто двадцать восемь бит, пишется восемью группами шестнадцатеричных цифр. Длинные нули можно сокращать: ведущие нули в группе убираем, а несколько нулевых групп подряд заменяем двумя двоеточиями, но только один раз. У каждого интерфейса автоматически есть link-local адрес на fe80 — как внутренний номер в офисе. Broadcast больше нет, вместо него multicast. На Cisco сначала включаем маршрутизацию командой ipv6 unicast-routing, потом вешаем адрес на интерфейс. Стандартная подсеть для LAN — слэш шестьдесят четыре.

Финальная строка-вывод: 128 бит, «::» один раз, LAN = /64.
```
