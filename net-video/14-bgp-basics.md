```text
Закадровый голос (спокойный, уверенный, по-русски):
BGP — это как переговоры между странами: каждая автономная система решает, через кого пускать свой трафик, по своей политике, а не по самой короткой дороге. Соседей задают вручную, сессия идёт по TCP-порту сто семьдесят девять. eBGP — между разными AS, iBGP — внутри одной. Чтобы анонсировать сеть, командой network её нужно объявить, и маршрут должен точно совпадать с тем, что есть в таблице маршрутизации. Выбор лучшего пути — по атрибутам: вес, local preference, длина AS-пути и дальше по списку. Если в summary вместо числа префиксов видишь Active или Idle — сессия не поднялась.

Финальная строка-вывод: BGP = политика между AS, соседи вручную, TCP 179.
```
