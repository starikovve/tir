# Урок 11. Статические маршруты

_Блок 3. Маршрутизация_

```text
Длительность: 60 секунд. Формат: вертикальное видео 9:16 (YouTube Shorts / TikTok).
Стиль: тёмный фон (почти чёрный), моноширинный шрифт, зелёный текст как в терминале, эффект набора текста. Без логотипов, без музыки на фоне голоса, без воды — только суть.

Тема: Урок 11. Статические маршруты.

Сюжет по сценам:
0–5 с — хук: Маршрутизатор не знает дорогу. Подскажем вручную.
5–20 с — Схема: R1 — 10.0.12.0/30 — R2 — сеть 192.168.2.0/24
20–40 с — Cisco: `ip route 192.168.2.0 255.255.255.0 10.0.12.2` · маршрут по умолчанию: `ip route 0.0.0.0 0.0.0.0 203.0.113.1` · плавающий резерв: `ip route 0.0.0.0 0.0.0.0 198.51.100.1 250`
40–55 с — `show ip route static` → S 192.168.2.0/24 [1/0] via 10.0.12.2
55–60 с — финальная строка крупно по центру: «ip route сеть маска next-hop [AD]. Просто, но не масштабируется.»

Закадровый голос (спокойный, уверенный, по-русски):
Статический маршрут — это как записка таксисту: «в этот район — через вот этот мост». Маршрутизатор сам ничего не узнаёт, ты говоришь ему: сеть такая-то — отправляй соседу с таким-то адресом. Маршрут по умолчанию, ноль ноль ноль ноль, — это «если не знаешь куда, вези в центр», обычно к провайдеру. Цифра в конце команды — административная дистанция. Если поставить двести пятьдесят, получится плавающий резервный маршрут: он появится, только когда основной пропадёт. Плюс статики — простота и предсказуемость. Минус — не масштабируется и сам не замечает обрыв дальше соседа.

Финальная строка-вывод: ip route сеть маска next-hop [AD]. Просто, но не масштабируется.
```
