```text
Тема: Урок 24. VPN: основы.

Сюжет по сценам:
0–5 с — хук: Как пустить трафик через интернет так, чтобы его никто не прочитал?
5–20 с — Схема: офис A — зашифрованный туннель через интернет — офис B · удалённый сотрудник → офис
20–40 с — IPsec: IKE (фаза 1 — защищённый канал, фаза 2 — SA для трафика) · ESP шифрует данные · порты UDP 500/4500 (NAT-T), протокол ESP 50
40–55 с — Cisco route-based: `interface Tunnel0` · `tunnel source Gi0/1` · `tunnel destination 198.51.100.2` · `tunnel mode ipsec ipv4` · `tunnel protection ipsec profile VPN` · `show crypto ipsec sa`

Закадровый голос (спокойный, уверенный, по-русски):
VPN — это как бронированный фургон, который едет по обычным улицам: дороги общие, а содержимое никто не видит. Site-to-site соединяет офисы, remote access подключает сотрудника из дома. Самый частый стандарт — IPsec. Сначала стороны по протоколу IKE договариваются и проверяют друг друга — ключом или сертификатом. Затем поднимаются туннели для данных, и ESP шифрует трафик. Если между ними NAT, всё заворачивается в UDP четыре пятьсот. На Cisco удобно делать туннельный интерфейс с профилем IPsec — по нему можно гонять маршрутизацию. Проверяем счётчики шифрования в show crypto ipsec sa.

Финальная строка-вывод: IPsec: IKE договаривается, ESP шифрует, туннель — обычный интерфейс.
```
