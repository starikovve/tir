# Урок 10. VTP

_Блок 2. Коммутация_

```text
Длительность: 60 секунд. Формат: вертикальное видео 9:16 (YouTube Shorts / TikTok).
Стиль: тёмный фон (почти чёрный), моноширинный шрифт, зелёный текст как в терминале, эффект набора текста. Без логотипов, без музыки на фоне голоса, без воды — только суть.

Тема: Урок 10. VTP.

Сюжет по сценам:
0–5 с — хук: Удобная функция, которая может стереть все VLAN в сети.
5–20 с — Схема: VTP server раздаёт список VLAN клиентам по trunk
20–40 с — Режимы: server · client · transparent · off (v3). Ловушка v1/v2: свитч с бо́льшим revision number перезаписывает VLAN всего домена
40–55 с — Безопасно: `vtp mode transparent` или v3: `vtp version 3` · `vtp mode server` · `vtp primary` (только один primary) · `show vtp status`
55–60 с — финальная строка крупно по центру: «VTP: transparent или v3 с primary, иначе риск стереть VLAN.»

Закадровый голос (спокойный, уверенный, по-русски):
VTP — это как общий чат, где один человек может переименовать всех участников. Сервер раздаёт список VLAN всем коммутаторам в домене. Удобно, но опасно: в версиях один и два новый свитч с большим номером ревизии может прийти и затереть VLAN во всей сети. Поэтому многие держат режим transparent — свитч не слушает чужие изменения. Если VTP нужен, используй третью версию: там изменения может вносить только назначенный primary server, это заметно безопаснее. Перед подключением нового коммутатора проверяй show vtp status и номер ревизии. В современных сетях VLAN всё чаще раздают автоматизацией, а не VTP.

Финальная строка-вывод: VTP: transparent или v3 с primary, иначе риск стереть VLAN.
```
