# Урок 19. DNS

_Блок 4. Сервисы_

```text
Длительность: 60 секунд. Формат: вертикальное видео 9:16 (YouTube Shorts / TikTok).
Стиль: тёмный фон (почти чёрный), моноширинный шрифт, зелёный текст как в терминале, эффект набора текста. Без логотипов, без музыки на фоне голоса, без воды — только суть.

Тема: Урок 19. DNS.

Сюжет по сценам:
0–5 с — хук: Ты вводишь имя сайта, а сеть понимает только цифры.
5–20 с — Анимация: клиент → резолвер → root → .ru → авторитетный сервер → ответ A 93.184.216.34
20–40 с — Типы записей: A (IPv4) · AAAA (IPv6) · CNAME (псевдоним) · MX (почта) · PTR (обратная) · NS · TTL — время в кэше
40–55 с — Терминал: `nslookup example.com` · `dig example.com A +short` · Cisco: `ip name-server 8.8.8.8` · `ip domain lookup`
55–60 с — финальная строка крупно по центру: «Имя → IP через резолвер и кэш, порт 53.»

Закадровый голос (спокойный, уверенный, по-русски):
DNS — это как телефонная книга интернета: ты помнишь имя друга, а книга подсказывает номер. Компьютер спрашивает свой резолвер, тот при необходимости идёт по цепочке: корневые серверы, потом зона домена, потом сервер, который точно знает ответ. Ответ запоминается в кэше на время TTL. Запись A даёт IPv4-адрес, AAAA — IPv6, MX указывает почтовый сервер, CNAME — псевдоним. DNS работает по порту пятьдесят три, обычно UDP, а большие ответы и передача зон идут по TCP. Если сайт открывается по IP, но не по имени — проблема почти наверняка в DNS.

Финальная строка-вывод: Имя → IP через резолвер и кэш, порт 53.
```
