```text
Стиль: тёмный фон (почти чёрный), моноширинный шрифт, зелёный текст как в терминале, эффект набора текста. Без логотипов, без музыки на фоне голоса, без воды — только суть.

Тема: Урок 12. OSPF.

Сюжет по сценам:
0–5 с — хук: Каждый маршрутизатор рисует полную карту сети. Это OSPF.
5–20 с — Анимация: hello между соседями → обмен LSA → у всех одинаковая LSDB → алгоритм Дейкстры (SPF)
20–40 с — Cisco: `router ospf 1` · `router-id 1.1.1.1` · `network 10.0.0.0 0.0.0.255 area 0` · `passive-interface Gi0/1` · стоимость = reference bandwidth / bandwidth
40–55 с — `show ip ospf neighbor` → FULL/DR · `show ip route ospf` → O 10.1.1.0/24 [110/2]
55–60 с — финальная строка крупно по центру: «OSPF: link-state, зона 0 — магистраль, соседи должны быть в FULL.»

Закадровый голос (спокойный, уверенный, по-русски):
OSPF — это как навигатор, у которого есть полная карта города, а не только советы прохожих. Маршрутизаторы знакомятся hello-пакетами, обмениваются описаниями своих линков и строят одинаковую карту. Потом каждый сам считает кратчайший путь по алгоритму Дейкстры. Метрика — стоимость, она зависит от скорости линка. Большие сети делят на зоны, и все зоны подключаются к нулевой, магистральной. Соседство не поднимется, если не совпадают таймеры hello, зона, маска или MTU. В выводе show ip ospf neighbor ищи состояние FULL. Интерфейсы к пользователям делай passive, чтобы не рассылать туда hello.

Финальная строка-вывод: OSPF: link-state, зона 0 — магистраль, соседи должны быть в FULL.
```
