# Урок 23. AAA

_Блок 5. Безопасность_

```text
Длительность: 60 секунд. Формат: вертикальное видео 9:16 (YouTube Shorts / TikTok).
Стиль: тёмный фон (почти чёрный), моноширинный шрифт, зелёный текст как в терминале, эффект набора текста. Без логотипов, без музыки на фоне голоса, без воды — только суть.

Тема: Урок 23. AAA.

Сюжет по сценам:
0–5 с — хук: Сто роутеров и один пароль admin на всех. Пора это менять.
5–20 с — Три буквы: Authentication (кто ты) · Authorization (что можно) · Accounting (что сделал)
20–40 с — Cisco TACACS+: `aaa new-model` · `tacacs server TAC1` · `address ipv4 10.0.0.50` · `key <секрет>` · `aaa authentication login default group tacacs+ local` · `aaa authorization exec default group tacacs+ local` · `aaa accounting commands 15 default start-stop group tacacs+`
40–55 с — Локальный резервный пользователь: `username backup privilege 15 secret <пароль>` · RADIUS — UDP, шифрует только пароль; TACACS+ — TCP 49, шифрует весь пакет
55–60 с — финальная строка крупно по центру: «Центральная проверка + локальный резерв = AAA.»

Закадровый голос (спокойный, уверенный, по-русски):
AAA — это как система пропусков в бизнес-центре: на входе проверяют личность, на этаже — куда тебе можно, а камеры записывают, где ты был. Authentication — кто ты, Authorization — что тебе разрешено, Accounting — журнал действий. Вместо локальных паролей на каждом роутере все входы проверяет центральный сервер TACACS плюс или RADIUS, часто связанный с Active Directory. Для управления сетевым оборудованием обычно выбирают TACACS плюс: он разделяет три функции и умеет авторизовать каждую команду. Обязательно оставь локального резервного пользователя, слово local в конце списка методов, иначе при падении сервера сам себя запрёшь.

Финальная строка-вывод: Центральная проверка + локальный резерв = AAA.
```
