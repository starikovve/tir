```text
Стиль: тёмный фон (почти чёрный), моноширинный шрифт, зелёный текст как в терминале, эффект набора текста. Без логотипов, без музыки на фоне голоса, без воды — только суть.

Тема: Урок 16. DHCP.

Сюжет по сценам:
0–5 с — хук: Компьютер включился и сам получил адрес. Кто ему дал?
5–20 с — Анимация DORA: Discover → Offer → Request → Acknowledge (UDP 67/68)
20–40 с — Cisco: `ip dhcp excluded-address 192.168.1.1 192.168.1.10` · `ip dhcp pool LAN` · `network 192.168.1.0 255.255.255.0` · `default-router 192.168.1.1` · `dns-server 192.168.1.5` · relay: `ip helper-address 10.0.0.5`

Закадровый голос (спокойный, уверенный, по-русски):
DHCP — это как администратор на ресепшене отеля: ты пришёл, сказал «мне нужен номер», и тебе выдали ключ, карту этажа и телефон ресторана. Клиент кричит на всю сеть Discover, сервер предлагает адрес — Offer, клиент соглашается — Request, сервер подтверждает — Ack. Вместе с адресом клиент получает маску, шлюз и DNS. Адреса для серверов и шлюза исключаем из пула. Если DHCP-сервер в другой сети, широковещательный запрос туда не дойдёт — на интерфейсе маршрутизатора ставим ip helper-address, это relay. Кто какой адрес получил — show ip dhcp binding.

Финальная строка-вывод: DORA, исключи статические адреса, в другом сегменте — helper-address.
```
