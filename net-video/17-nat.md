# Урок 17. NAT

_Блок 4. Сервисы_

```text
Длительность: 60 секунд. Формат: вертикальное видео 9:16 (YouTube Shorts / TikTok).
Стиль: тёмный фон (почти чёрный), моноширинный шрифт, зелёный текст как в терминале, эффект набора текста. Без логотипов, без музыки на фоне голоса, без воды — только суть.

Тема: Урок 17. NAT.

Сюжет по сценам:
0–5 с — хук: Сто устройств в офисе и один публичный адрес. Как?
5–20 с — Схема: 192.168.1.10:51000 → 203.0.113.5:51000 → интернет (PAT по портам)
20–40 с — Cisco PAT: `access-list 1 permit 192.168.1.0 0.0.0.255` · `ip nat inside source list 1 interface Gi0/1 overload` · `interface Gi0/0` `ip nat inside` · `interface Gi0/1` `ip nat outside`
40–55 с — Static NAT для сервера: `ip nat inside source static 192.168.1.20 203.0.113.10` · `show ip nat translations`
55–60 с — финальная строка крупно по центру: «PAT = много внутренних → один внешний, не забудь inside/outside.»

Закадровый голос (спокойный, уверенный, по-русски):
NAT — это как секретарь в офисе: все звонки наружу идут с одного общего номера, а секретарь помнит, кто из сотрудников кому звонил. Внутренние частные адреса подменяются на публичный адрес маршрутизатора. Чтобы через один адрес выходили многие, используется PAT — разделение по номерам портов, в Cisco это слово overload. Важно отметить интерфейсы: внутренний — inside, внешний — outside, без этого ничего не заработает. Для сервера, к которому должны приходить снаружи, делаем статический NAT — постоянное соответствие адресов. Таблицу трансляций смотрим командой show ip nat translations.

Финальная строка-вывод: PAT = много внутренних → один внешний, не забудь inside/outside.
```
